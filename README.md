# Global Claude Code Configuration

## Design Systems

For all UI/frontend work, design system references are available in `~/.claude/design-systems/`. When the user asks to build UI inspired by a specific brand, read the corresponding DESIGN.md file and follow its design tokens, colors, typography, spacing, and component patterns.

62 design systems installed. All files follow the pattern `<brand>-DESIGN.md`.

**AI & LLM:** claude, cohere, elevenlabs, minimax, mistral.ai, ollama, opencode.ai, replicate, together.ai, x.ai
**Developer Tools:** cursor, expo, figma, framer, hashicorp, linear.app, lovable, miro, mintlify, posthog, raycast, resend, sanity, sentry, vercel, voltagent, warp, webflow, zapier
**Fintech & Crypto:** stripe, binance, coinbase, kraken, revolut, wise
**Consumer & Social:** airbnb, meta, nike, notion, pinterest, shopify, spotify, superhuman, uber
**Data & Infrastructure:** airtable, clickhouse, mongodb, nvidia, supabase, composio
**Automotive & Luxury:** bmw, ferrari, lamborghini, renault, spacex, tesla
**Enterprise & Design:** apple, cal, clay, ibm, intercom, runwayml, semrush (N/A)

To add more: `npx getdesign@latest add <brand-name>` then save to `~/.claude/design-systems/<brand>-DESIGN.md`
